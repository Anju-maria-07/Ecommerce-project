# Ecommerce-project

An e-commerce website built using React and Vite.

## Project Setup

To run this project locally:

1. Install the project dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL displayed in your terminal.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
